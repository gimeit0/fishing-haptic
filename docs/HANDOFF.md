## 0. 30秒サマリ

- **何を作っているか**: ボイスコイル型加振器を組み込んだのべ竿型デバイスで、魚釣りの「アタリ（餌を突く微振動）」と「引き（牽引力錯覚）」を単一デバイス上で触覚提示する研究プロトタイプ。
- **今どこまで**: M5StickS3 単体で動く8状態の釣りシミュレータ（LCD+IMU+ブザー）に、I2S→MAX98357A→加振器の触覚出力を統合済み。**実機で加振器の振動を確認済み**。波形・時間パラメータのチューニングを反復中。
- **次にやること**: 予備評価（研究室内）で刺激パラメータを確定 → 主観評価実験の実装（条件切替・データ記録）→ 実験実施。
- **一番の技術的空白**: 実験用の「対照条件（対称振動）」と「データ記録機能」が未実装。下記 §4 参照。

## 1. プロジェクトの狙い（なぜやるか）

先行研究2件を**単一の小型・非接地デバイス上で初めて統合**するのが貢献の核。

| 先行研究 | 内容 | 本プロジェクトでの実装 |
|----------|------|----------------------|
| 才木ら 2016 | 実釣のアタリ振動は 10Hz・23Hz にピーク。竿元には竿先の約1/5しか伝わらない | NIBBLE/BITE 状態で 10+23Hz 合成波を**増幅**提示 |
| 高椋ら 2016 | 5ms高+T msの非対称矩形波で牽引力錯覚。T≥12msでリアリティ高 | FIGHTING 状態で非対称矩形波を提示 |

高椋ら自身が挙げた limitation が本研究の2つの改善点：
1. **刺激が規則的すぎて活物感に欠ける** → 「魚行動×操作×ジッタ」の3層で不規則性を付与（§3.3）
2. **装置形態が釣具と違う** → のべ竿型（VP40 塩ビ管グリップ）に実装

### 3.2 状態機（8状態）とデータフロー

```
IDLE →(BtnA)→ CASTING →(1s)→ WAITING →(3-8s)→ NIBBLE →(3.5-6s)→ BITE
                                                                    ↓(IMUで合わせ |a|>1.5g、1s以内)
CAUGHT/FAILED ←──────────────── FIGHTING(20-30s、上提でゾーン維持) ←┘
```

- `loop()` (main.cpp 末尾) が毎フレーム: `M5.update()` → `pollSerial()` → `updateLogic()` → `updateHaptics()` → 描画。約60fps。
- `updateLogic()`: 状態ごとの遷移ロジック。BITE の合わせ検出（加速度スパイク）、FIGHTING の上提検出（ジャイロスパイク+ヒステリシス+不応期）はここ。
- `updateHaptics()`: **ゲーム状態→触覚モードの写像はここ一箇所**。FIGHTING 中の振幅・パルス間隔の計算もここ。
- `haptics.cpp` の `hapticTask()`: Core0 で 8ms 毎にサンプル合成 → `i2s_write()`。描画負荷と分離。

### 3.3 触覚刺激の設計（実装済み）

**アタリ（NIBBLE/BITE）** — 才木ら 2016
- `s(t)=A[0.58·sin(2π·10t)+0.42·sin(2π·23t)]`。10Hz を重め（0.58）にして MAX98357A の ~14Hz HPF による減衰を補償。
- NIBBLE: 200–500ms burst + 250–800ms 間隔（ランダム）、15ms 包絡でクリック防止。振幅 `NIBBLE_AMP_DEF=0.55`。
- BITE: 同波形を連続・振幅2.2倍（≈満幅）。

**引き（FIGHTING）** — 高椋ら 2016 + 不規則性拡張
- `周期 = 5ms高(+A) + T ms低(−A·5/T)`、時間平均ゼロ（DCフリー）。
- **不規則性3層モデル**（`ir 1`、既定）:
  1. 魚行動層: `driftPerSec`（突進52 / 休息4 / 通常12-30 を0.55-1.1s毎に再抽選）が**画面のマーカー減衰と触覚振幅の両方**を決める→視触覚が常に一致。さらに捕獲進度で引きが100%→65%に**疲労**。
  2. 操作層: マーカー位置（竿姿勢）で振幅×0.85-1.15、上提直後400msは最大+35%。
  3. 微視層: パルス毎に T±2ms ジッタ、0.9Hz 振幅ゆらぎ。
- `ir 0` で全不規則性を切り、恒定振幅・固定Tの規則刺激になる（§4.1 の注意点あり）。

### 3.4 シリアルコマンド（予備評価用、115200bps）

`pio device monitor -p COM3 -b 115200` で接続。

| cmd | 機能 |
|-----|------|
| `t n/b/p/0` | 触覚モード強制（nibble/bite/pull/off）。台架試験用 |
| `t g` | ゲーム連動に戻す（既定） |
| `pa <0-1>` | 引き振幅スケール |
| `pt <ms>` | パルス間隔T固定（`pt 0`で自動） |
| `na <0-1>` | アタリ振幅 |
| `ir 0/1` | 不規則性 off/on |

### 3.5 これまでのチューニング履歴（体感フィードバックに基づく）

| 項目 | 旧 | 現 | 理由 |
|------|----|----|------|
| FIGHTING 維持目標 | 3-5s | 12-18s（全程20-30s） | 対抗が短すぎた。SoT~45s と Stardew~10-20s の中間 |
| アタリ振幅 | 0.35 | 0.55 | 黄色NIBBLE段が弱すぎた。才木らの主旨は「増幅提示」 |
| NIBBLE 持続 | 1.5s固定 | 3.5-6s ランダム | burst 1-2個しか出ず設計が展開しない/BITE到来が予測可能だった |
| 上提量 PUMP_RISE | 16 | 20 | 長期戦で約1回/秒の挙竿で維持できるように |
| ESCAPE_LIMIT | 2.2s | 3s | 長期戦化に伴う緩和 |
| 魚の休息/疲労 | なし | 追加 | 活物感（一冲一停・終盤に弱る）の付与 |

## 4. 次にやるべきこと & 不足しているもの

### 4.1 【最優先】実験の対照条件を正す

研究計画書 3.4 は比較条件として「**同一加振器による対称振動**」を挙げている。高椋ら 2016 の対照も対称振動（図4b: 高低とも12ms）。
**しかし現状の `ir 0` は「非対称波のまま振幅・Tを固定した規則刺激」で、対称振動ではない。**
→ 対称矩形波（例: 12ms高 +12ms低、正負対称でDCフリー）を出す条件を別途実装し、実験の対照とする必要がある。`pullSample()` に対称モードを追加するのが素直。

### 4.2 【必須】実験データ記録機能

現状は `Serial.printf` のログのみ。主観評価実験では「試次ごとの刺激条件 + 被験者評定（6-7件法×5項目）」を構造化して残す必要がある。案:
- 各試次のパラメータ（振幅・T・不規則性on/off・魚種・holdTarget等）を試次IDと共にシリアルへCSV出力し、PC側で記録。
- または SD/PSRAM に保存。M5StickS3 は SD スロットが無いので PC 記録が現実的。

### 4.3 【必須】実験モード（デモモードと別）

現状は自動で回るデモ。実験には: 条件のランダム化/カウンターバランス、試次間の休止、評定入力の待ち、被験者ID管理 が要る。デモと実験でビルドを分けるか、起動時にモード選択する設計を検討。

### 4.4 評価項目（計画書 3.4、実装済みのハードは揃っている）

アタリ感の知覚しやすさ / 引き感の強さ / アタリ感と引き感の区別しやすさ / 魚の引きとしてのリアリティ / 没入感・楽しさ。各6-7件法。
→ **本研究独自の対比**: `ir 0`(規則) vs `ir 1`(不規則) でリアリティが上がるか。先行研究の limitation を直接検証する目玉。

### 4.5 機械・ハード面

- VP40 塩ビ管への加振器固定方法の検討（8月、計画書 3.4）。固定方式で振動伝達が変わる。
- 低域出力が必要なら DAEX25FHE-4 への換装判断（8月）。
- 加振器・アンプ・バッテリの管内収納レイアウト。

### 4.6 未検証・要実測

- **MAX98357A の 14Hz HPF が 10Hz をどれだけ減衰するか未実測**。加速度計で加振器の実際の周波数応答を測り、10Hz 成分が残っているか確認すべき（残っていなければアタリ設計の見直しが必要）。
- 牽引方向の極性確認（手前に引かれる向きか）。逆なら `haptics.cpp` の `PULL_POLARITY` を -1 に。
- 内蔵ブザーの音効が触覚評価に干渉しないか。実験時はブザー無音化が要るかも（`cfg.internal_spk` や `beep()` の抑制）。
