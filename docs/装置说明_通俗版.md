## 一、这是个什么东西

一根**会骗手的钓竿**。

竿上没有鱼,也没有水。竿身上贴着一个硬币大小的振动器(和高级手机里
让你感觉"咔哒"一下的元件同类,但更强力),由一块名片大小的小电脑
(屏幕上跑着钓鱼流程)指挥它振动。振动经过精心设计,让握竿的手产生
"有鱼在水下拉扯"的错觉——鱼咬钩的"叩叩"、挣扎的拉拽、越拉越沉的手感,
全部是振动画出来的。

**研究问题只有一个:只靠手上的振动,人能不能分辨钓到的是大鱼还是小鱼?**

## 二、它是怎么"骗手"的(设计思想)

### 1. 咬钩 = 敲门声,不是嗡嗡声

鱼碰饵的真实手感是"叩、叩"的敲击,不是电动牙刷那种持续嗡嗡。所以咬钩
阶段我们输出的是一下一下的**敲击事件**:一记短促的"叩"加上竿身余颤,
稀疏随机地出现——像有人隔一会儿敲一下门,你永远猜不到下一下什么时候来。

### 2. 拉拽感 = 一个方向上的"急拉慢放"魔术

振动器只会原地抖,怎么让手感觉"被朝前拽"?用一个经过学界反复验证的
错觉:**急促地朝一个方向猛推、再慢慢收回来**,如此反复。手对"猛"的
那一下敏感、对"慢"的回程迟钝,于是只记住了一个方向的力——就像有人
不停快速抽走你手里的绳子,你会觉得绳子在持续往那边拉。
(这个错觉的谱系来自东京大学雨宮研究室/NTT 一系的研究,本项目的
波形直接基于该谱系的钓鱼应用文献。)

### 3. 钓法 = "弯住竿子耗鱼",不是摇卷线器

这根竿是**延べ竿**——没有卷线器,收不了线。真实的延べ竿搏鱼方式就是
把竿抬高弯住、保持张力慢慢耗("ため")。所以游戏规则是:**竿抬高保持,
振动=鱼在抵抗,进度条一格格填满;竿放平,振动立刻消失**——因为振动
本来就是顺着绷紧的钓线传到手上的,线一松什么都传不过来。这条
"拉紧才有、放松就没"的规则,是整个手感真实性的地基。

抬得太高会怎样?先是"嗒嗒嗒"的**泄力打滑**警告(渔轮泄力器出线的声音
和手感),再不收敛就**断线**——和真钓鱼一样,蛮力是要付代价的。

### 4. 大小鱼 = 三种线索同时说同一句话

大鱼和小鱼的差别,同时写进三个维度:

| 维度 | 大鱼 | 小鱼 | 生活比喻 |
|------|------|------|----------|
| **力气**(振动强度) | 强 | 弱(约六成) | 拔河对手是壮汉还是小孩 |
| **动作快慢**(振动频率) | 慢而沉,"咚——咚——" | 快而碎,"哒哒哒哒" | 大狗低吠,小狗尖叫;大钟低鸣,小铃高响 |
| **余韵**(每拉近一格的"咚") | 拖尾长,"咚嗡——" | 干脆,"嗒" | 敲大鼓和敲小鼓的区别 |

三条线索方向一致、互相佐证。特别值得一提的是"慢=大":感知研究发现
**低频振动会让手里的东西感觉更重**,而钓鱼老手判断鱼大小靠的也正是
这个——竿上"ブルブル"细颤是小鱼,"ドンドン"沉顿才是大物。我们把
钓手真实使用的判断线索,原样编码进了振动里。

### 5. 公平性:不许"作弊"

如果大鱼要打 20 秒、小鱼 8 秒,被试数秒数就能猜对,实验就废了。所以
**两种鱼的战斗结构完全一样**(都是 4 格进度、每格约 3 秒),失败规则、
音效、画面全部相同;还有**盲测模式**,把屏幕上所有会泄露答案的信息
(大小标签、鱼种名、参数行)全部藏起来,连切换条件的提示音都统一。
被试能依赖的,只剩手上的振动。

### 6. 两个贴心的小设计

- **待机心跳**:装置闲着的时候,每 25 秒手上轻轻"扑通、扑通"跳一下——
  告诉你它还活着,顺便让充电宝不会因为"没人用电"而自动断电。
- **限力阀**:大鱼全力发威时的耗电峰值会把小电脑的供电拉垮导致重启
  (屏幕会用红字 `rst:BROWNOUT` 告诉你发生过),所以固件里装了一个
  "限力阀"压住峰值。彻底解决要靠加装一颗电容(方案已备好,见
  `changes/2026-08-26-brownout供电对策记录.md`)。

## 三、操作说明

### 3.1 开机检查(每次演示/实验前 30 秒)

1. 按充电宝按键启动供电,屏幕亮起;
2. 看屏幕**左上角**:绿色 `EXT` = 供电正常;橙色 `BAT` = 外部电源断了,
   振动会没有,重按充电宝按键;
3. 看屏幕中部 `rst:` 一行:灰色(POWERON/SW)正常;红色 `BROWNOUT`
   说明上次是被"拉垮"重启的,记下来报告即可;
4. 待机时手上每 25 秒一次轻微心跳 = 振动系统正常。

### 3.2 钓一条鱼(被试看这段就够)

1. **抛竿**:按正面大按钮(BtnA),画面演示抛出;
2. **等待**:水波画面,安静等;
3. **试探**:画面变黄、手上"叩…叩…"——鱼在碰饵,**先别动**;
4. **咬钩**:画面变红闪烁 BITE!! + 急促警报——**1 秒内猛地向上提竿**;
5. **搏鱼**:把竿**抬高并保持住**(画面绿字 HOLD),手上的振动就是鱼的
   抵抗;顶部进度条 4 格逐格填满,每满一格手上"咚"一下=鱼被拉近一段;
   - 黄字 `DRAG SLIPS!` + 嗒嗒声 = 抬太高在泄力,稍微放低;
   - 红字 `TOO HIGH!` = 危险!马上放低,硬顶 1 秒多就断线;
   - 竿放平太久(6 秒)= 鱼跑了;
6. **钓上**:CAUGHT! 显示鱼——结束,回到待机。

全程约 20 秒。失败了(跑鱼/断线)也会自动回到待机,再按 BtnA 重来。

### 3.3 切换大鱼/小鱼

待机画面按**侧面小按钮(BtnB)**:屏幕 `fish:SML ⇔ fish:BIG`,
小鱼=高提示音,大鱼=低提示音。断电重启后回到小鱼。

### 3.4 实验者:盲测流程

需要一台连着板子的电脑(串口 115200)。打开串口监视器:

```powershell
& "$env:USERPROFILE\.platformio\penv\Scripts\pio.exe" device monitor -p COM3 -b 115200
```

(端口号:1号机 COM3 / 2号机 COM4 / 3号机 COM6,以 `pio device list` 为准)

每场实验只需要三条命令:

| 敲入 | 作用 |
|------|------|
| `bl 1` | 开盲测:屏幕隐藏所有大小线索,按钮提示音统一 |
| `fm 0` / `fm 1` | 本局设为 小鱼 / 大鱼(按随机表来,被试看不到) |
| (读日志) | 每局开始自动打印 `cond=BIG size=0.85 …` = 正解记录 |

流程:`bl 1` → 每局 `fm x` → 被试玩一局 → 口头回答"大/小" → 与串口
日志对照记分。注意所有串口设置**断电即失效**,每天开机重新设一遍。

### 3.5 出问题了看这里

| 现象 | 原因与处置 |
|------|------------|
| 战斗中黑屏重启,回来后 `rst:BROWNOUT` 红字 | 供电被拉垮(已知问题,大鱼条件偶发)。演示可继续;根治方案(加电容)见对策文档 |
| 完全没振动 | ① 左上角是不是橙色 BAT → 重按充电宝;② 板子和功放之间的线是否松动 |
| 拉拽感方向反了(像推不像拉) | 振动器两根线接反了,对调即可 |
| 屏幕黑着无反应 | 拔插一次 USB / 按侧面电源键 |
