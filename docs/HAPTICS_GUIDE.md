# 触覚提示システム 操作説明書 / 触觉系统操作说明

のべ竿型 VR 釣り具プロトタイプ ― ファームウェア操作・チューニングガイド
（JAIST 木谷研究室 / 研究計画書 v3.0.0 対応）

---

## 1. 系统概述 / システム概要

固件由两层组成，跑在同一块 M5StickS3 上：

| 层 | 文件 | 作用 |
|----|------|------|
| 游戏层（体验设计） | `src/main.cpp` | 8 状态钓鱼流程、LCD 画面、IMU 动作检测、音效 |
| 触觉层（刺激生成） | `src/haptics.cpp` | 波形逐样本合成 → I2S (16kHz) → MAX98357A → 音圈激振器 |

两层通过 `updateHaptics()`（main.cpp）连接：**游戏进入哪个状态，激振器就自动播放对应的触觉波形**。没接 MAX98357A 时游戏照常运行，只是没有振动。

## 2. 硬件接线 / 配線

| M5StickS3 | MAX98357A | 信号 |
|-----------|-----------|------|
| 5V | VIN | 電源 |
| GND | GND | GND |
| GPIO4 | BCLK | ビットクロック |
| GPIO5 | LRC | LR チャンネル選択 |
| GPIO6 | DIN | 音声データ |

MAX98357A 的 OUT+ / OUT− 接激振器（DAEX19CT-4 或 EX25FHE2-4，均为 4Ω）。

## 3. 游戏状态 → 触觉刺激的映射 / 状態と刺激の対応

```
IDLE → CASTING → WAITING → NIBBLE → BITE → FIGHTING → CAUGHT / FAILED
 (静音)   (静音)    (静音)    ↓アタリ   ↓アタリ強  ↓引き波形      (静音)
```

| 游戏状态 | 触觉模式 | 波形内容 | 文献依据 |
|----------|----------|----------|----------|
| NIBBLE（前アタリ，持续 3.5–6s 随机） | `HAPTIC_NIBBLE` | 10Hz+23Hz 合成正弦波，200–500ms 短 burst，间隔 250–800ms 随机（一局可感受 4–6 个 burst） | 才木ら 2016 |
| BITE（本アタリ） | `HAPTIC_BITE` | 同波形**连续**输出，振幅约 2.2 倍 | 才木ら 2016 |
| FIGHTING（やり取り） | `HAPTIC_PULL` | 5ms 高电压 + T ms 低电压 非对称矩形波（牵引力错觉） | 高椋ら 2016 |
| 其余状态 | `HAPTIC_OFF` | 静音 | ― |

**FIGHTING 中的动态联动（不规则性三层模型）**：

高椋ら (2016) 在考察中承认，严格周期性的刺激缺乏真鱼的不规则性，是リアリティ评分停在 4.7/6 的主因之一。本固件用三层结构解决，且所有随机源都来自游戏逻辑，保证**画面和手感永远一致**：

1. **鱼行为层**：鱼的拉力 `driftPerSec` 每 0.55–1.1 秒随机重抽——10% 突进（拉力 52）/ 18% 休息（拉力 4，引き骤松）/ 其余正常（12–30）。这个值同时决定屏幕光标的下坠速度**和**触觉振幅（振幅 ≈ driftPerSec/52，休息时保留 12% 底线张力）。另有**疲劳弧线**：随捕获进度鱼的拉力衰减至 65%——序盘凶猛、终盘乏力，"快钓上来了"直接通过手上振幅变弱传达。
2. **张力层（用户操作耦合）**：
   - 竿的姿态：光标位置越高（竿立得越起）振幅 ×0.85→×1.15——**下放弱、抬起强**；
   - 上提瞬间：陀螺仪检测到 pump 后 400ms 内振幅最高 +35%，线性衰减——每次发力手上都有即时反馈。
3. **微观层**：每个脉冲周期给 T 加 ±2ms 随机抖动（抖动后仍保持 DC-free），外加 ~0.9Hz 低频振幅摆动——打破"冲击钻"式的严格周期性。

脉冲间隔 T 仍随拉力粗细联动：22ms（弱）→ 12ms（突进）。当前振幅和 T 值显示在 FIGHTING 画面下方（`A:xx% T:xxms`）。

用 `ir 0` 可整体关闭以上不规则性，回到高椋ら式的恒定振幅、严格周期刺激——作为主观评价实验的**对照条件**（规则 vs 不规则）。

## 4. 串口调试命令 / シリアルコマンド ★

用于**预备评价阶段的参数扫描**和台架测试。连接方法：

```powershell
& "$env:USERPROFILE\.platformio\penv\Scripts\pio.exe" device monitor -p COM3 -b 115200
```

打开监视器后直接输入命令 + 回车。

### 4.1 `t` ― 触觉模式强制（test）

绕过游戏状态机，直接命令激振器输出某种波形。**用途：不用玩完整局游戏就能单独测试/演示某个刺激**。

| 命令 | 含义 | 效果 |
|------|------|------|
| `t n` | test **n**ibble | 强制输出アタリ波形（10+23Hz 随机 burst），持续不停 |
| `t b` | test **b**ite | 强制输出本アタリ（连续、更强） |
| `t p` | test **p**ull | 强制输出引き波形（非对称矩形波）→ 手上应有被"拉"的感觉 |
| `t 0` | test off | 强制静音 |
| `t g` | **g**ame | 解除强制，回到游戏状态自动控制（默认状态） |

> 典型验收流程：接好硬件 → `t p` 确认有牵引感且方向朝手前 → `t n` 确认微弱断续振动 → `t g` 回到游戏。

### 4.2 `pa` ― 引き振幅缩放（pull amplitude）

```
pa 0.8        ← 引き波形整体振幅 ×0.8（范围 0–1，默认 1.0）
```

游戏联动的 45–100% 振幅会再乘这个系数。预备评价确定"实用振幅范围"时用。

### 4.3 `pt` ― 脉冲间隔 T 固定（pull T）

```
pt 17         ← 把 T 固定为 17ms（高椋ら推荐 T≥12ms）
pt 0          ← 恢复自动（随鱼挣扎在 12–22ms 间变化）
```

固定 T 后可做单变量对比（比如 12 / 17 / 22ms 三条件的粗さ评价）。

### 4.4 `na` ― アタリ振幅（nibble amplitude）

```
na 0.5        ← アタリ振动振幅设为 0.5（范围 0–1，默认 0.55）
```

アタリ是"微弱刺激"，从小往大调，找到刚好可感知的水平（知覚閾探索）。

### 4.5 `ir` ― 不规则性开关（irregularity）

```
ir 0          ← 规则模式：恒定振幅 0.7、固定 T=17ms、无抖动无摆动（高椋ら 2016 准拠）
ir 1          ← 不规则模式：鱼行为×张力×抖动 三层模型（默认）
```

**这是主观评价实验的核心对照条件**：先行研究的 limitation 是刺激缺乏不规则性，本研究可通过 `ir 0` vs `ir 1` 的组内比较直接检验"不规则性是否提升魚の引きとしてのリアリティ"。

### 4.6 组合示例：预备评价一次扫描

```
t p           ← 进入持续引き模式
pt 12         ← 条件1: T=12ms
pt 17         ← 条件2: T=17ms
pt 22         ← 条件3: T=22ms
pa 0.5        ← 再扫振幅…
t g           ← 结束，回到游戏
```

⚠ 强制模式和参数在**断电/复位后失效**，恢复默认值。要改默认值需改代码：
`haptics.cpp` 的 `NIBBLE_AMP_DEF` / `PULL_INTERVAL_DEF`，`main.cpp` 的 `PULL_STR_MIN/MAX`、`PULL_T_SLOW/FAST`。

## 5. 游戏操作 / ゲーム操作

| 状态 | 操作 |
|------|------|
| IDLE | 按 **BtnA** 抛竿 |
| BITE | 1 秒内**猛提竿**（加速度 >1.5g，IMU 检测；BtnA 兜底） |
| FIGHTING | 反复**上提竿**（陀螺仪检测，约 1 次/秒），把光标保持在两条红线间的甜区，攒满 12–18 秒的区内累计时间即 CAUGHT（全程体感 20–30 秒，参考 Sea of Thieves ~45s 与 Stardew Valley ~10-20s 的中间值）。脱区连续 3 秒或光标掉到 0 = 跑鱼 |

## 7. 故障排查 / トラブルシューティング

| 现象 | 原因与对策 |
|------|-----------|
| 屏幕黑屏、串口只显示 `waiting for download` | 芯片被 DTR/RTS 时序带进下载模式。**拔插一次 USB** 即可；或运行 `esptool.py --chip esp32s3 --port COM3 --after hard_reset read_mac` |
| `t p` 时牵引方向反了（感觉向前推不是向手前拉） | 改 `haptics.cpp` 的 `PULL_POLARITY` 为 `-1.0f`，或把激振器 OUT+/OUT− 接线对调 |
| アタリ振动很弱、几乎感觉不到 | ① `na` 调大试试；② MAX98357A 内部有 ~14Hz 高通滤波，10Hz 成分会衰减（代码里已对 10Hz 加权补偿）；③ 检查激振器与管壁的固定是否松动 |
| 引き波形有"咔哒"杂音 | 正常现象的可能性大——非对称矩形波本身就是尖锐脉冲；若是模式切换瞬间的爆音，已有交叉淡入淡出抑制，仍明显时把 `haptics.cpp` 中 masterEnv 的时定数调慢 |
| 游戏能玩但完全无振动 | 开机串口 banner 查看 `I2S=ok` 还是 `N/A`；检查 GPIO4/5/6 接线和 MAX98357A 供电 |
| PowerShell 手动开串口收不到回显 | USB-Serial/JTAG 的已知问题，用 `pio device monitor` 代替 |

## 8. 波形规格速查 / 波形仕様

**アタリ（NIBBLE/BITE）** ― 才木ら 2016
```
s(t) = A·[0.58·sin(2π·10t) + 0.42·sin(2π·23t)]
NIBBLE: burst 200–500ms + 间隔 250–800ms（随机），15ms 包络防爆音
BITE:   连续，A×2.2
（10Hz 加权是为补偿 MAX98357A 的 ~14Hz 高通）
```

**引き（FIGHTING）** ― 高椋ら 2016
```
周期 = 5ms(高电压 +A) + T ms(低电压 −A·5/T)   ← 时间平均为零(DC-free)
T ∈ 12–22ms（推荐域 T≥12ms），振幅=引き強さ，T=粗さ
不规则模式(ir 1)下另加: T±2ms/周期抖动、0.9Hz 振幅摆动(75–100%)、
鱼行为(突进/休息/正常)与用户操作(竿姿态/上提)的振幅联动
```

**高椋ら 2016 实验结论速记**（原文 8 页已读，要点）：
- 牵引强度只由振幅决定；粗糙感随 T 和振幅增大
- リアリティ ≈ 0.27×牵引强度 + 0.65×粗糙感（粗糙感是最大贡献项，"扑腾感"本身是好的）
- T≥12ms 各条件リアリティ均显著优于 7ms；最优条件也仅 ~4.7/6
- 作者归因：①刺激缺乏不规则性 ②装置形态不像钓具 —— 即本研究的两个改进点

实现位置：`src/haptics.cpp`（合成任务跑在 Core 0，I2S_NUM_1，16kHz/16bit）。
