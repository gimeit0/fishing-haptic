| 要求 | 实装 |

## 2. 模式切换(旧模式完整保留)

- **默认仍是旧 PUMP 模式**(泵竿+甜区,已验证可靠)。
- 切换方式:IDLE 画面按 **BtnB**(屏幕显示 `mode:HOLD/PUMP`),或串口 **`fm 1`**(HOLD)/ **`fm 0`**(PUMP)。断电后回到默认。

## 3. HOLD 模式详细规则

- **倾角测量**:当前重力向量(加速度低通)与"静止基线向量"的夹角——
  基线在 IDLE/CASTING/WAITING/NIBBLE 期间自动学习(角速度 <30°/s 时低通更新),
  FIGHTING 中冻结。**不依赖设备在竿上的安装朝向**。
- **负荷判定**:>18° 进入负荷,<12° 退出(滞回防抖)。BtnA 按住可强制负荷
  (IMU 不调/桌面测试兜底)。
- **失败条件**:
  - 未负荷连续 6s → "Ran off!"(线松太久鱼跑了);
  - 倾角 >55° 保持(前田图中的 ×:大甩竿/过度强拉)→ 高音警告 + 剧烈画面抖动,
    连续 1.2s → **"Line broke!"**(新失败原因);
- **未负荷时**当前段进度以 0.4× 实时速度回退(鱼往回要线),完成段不回退。
- **段完成**:触觉瞬态敲击(`hapticTriggerTap`)+ 上升音阶 + 白闪。
- 鱼行为层(突进/休息/正常 + 疲劳弧线)照常运行,继续驱动负荷中的振幅纹理
  和 slack/突进事件;疲劳进度改由段进度驱动。
- 运动耦合(mc)在 HOLD 模式**不适用**——倾角门控本身就是 action-coupling
  的替代且更贴合钓线物理;mc 只作用于 PUMP 模式。

## 4. 文献依据(可回复前田时引用)

- 高椋ら 2016(项目基础文献):振动增益·频率的系统控制可调制"鱼大小的印象"
  → 尺寸→振幅映射的直接依据。
- SIGGRAPH Asia 2024《Interactive Virtual Fishing…Line Slack》:张力高→力反馈、
  line slack→力骤失 → "放竿静音"的依据。
- CHI 2025《Motion-Coupled Asymmetric Vibration》:振动与用户用力阶段耦合更受
  偏好 → "只在拉着时振动"的依据。
- CHI 2024《Experiencing Dynamic Weight Changes…Vibrotactile Feedback》:
  振动强度∝重量可被感知 → 强弱传达抵抗/大小的依据。

## 5. 待实机调的参数(均在 main.cpp 顶部)

| 参数 | 预设 | 说明 |
|------|------|------|
| `TEN_TILT_ON/OFF` | 18°/12° | 负荷判定滞回。装上竿后按实际动作幅度调 |
| `TEN_TILT_FULL` | 45° | 张力系数最大的倾角 |
| `TEN_TILT_OVER` / `TEN_OVER_MS` | 55°/1.2s | 过拉断线判定 |
| `TEN_UNLOAD_LIMIT` | 6s | 松线逃鱼时限 |
| 段数/段时长 | 3–5 段 × 2.5–4s | 由鱼尺寸决定,总时长约 7.5–20s |
