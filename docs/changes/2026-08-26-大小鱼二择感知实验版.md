## 2. 为什么段数/段长默认不随尺寸变(dc 0)

旧设计里大鱼 5 段×3.85s≈19s、小鱼 3 段×2.65s≈8s——被试只要数秒数就能
"猜"对大小,**战斗时长是比触觉强得多的结构线索**,会淹没本研究想测的
触觉通道。默认把两条件的游戏结构完全对齐(4 段×3.2s,全长约 12.8s+回退),
使 BIG/SML 的差异**只**存在于:

1. 振幅系数 sizeFac:SML 0.64 vs BIG 0.94(比率 ≈1.5,远超振幅 Weber 比)
2. 基本周波数:SML T-3ms(约 36–55Hz)vs BIG T+4ms(约 29–40Hz)
3. 段完成瞬态余振 τ:SML 76ms(脆)vs BIG 128ms(沉)

演示/展会场景用 `dc 1` 恢复"大鱼更难钓"的游戏性联动。

## 3. 盲测模式 `bl 1`

隐藏所有屏幕/声音上的答案泄露:IDLE 的 `fish:BIG/SML` → `fish:?`;
FIGHTING 的 `[BIG/MID/SML]` 标签 → `[?]`;`A:xx% T:xxms` 调试行(T 值
会泄露条件)整行隐藏;CAUGHT 的鱼种名(尺寸的答案)→ `? ? ?`;
BtnB 切换音统一为 1000Hz(平时大=500Hz 低音/小=1600Hz 高音)。

串口不受影响——`STATE -> FIGHTING cond=BIG size=0.85 seg=4 x 3200ms
blind=1 couple=0` 是实验者的正解记录,与被试口头回答对照即可算弁別率。

## 4. 推荐实验流程(2AFC 弁別)

1. `bl 1` 开盲测;被试持竿,实验者持串口(被试看不到)
2. 每试行 `fm 0` 或 `fm 1` 按随机表设条件 → 被试玩一局 → 口头报告"大/小"
3. 串口日志自动带正解;若要拉开/缩小差异,`fs`/`fb` 调两个水准值
   (如 `fs 0.35` `fb 0.7` 测更难的弁別)
4. 变量切分:`hf 0` 关掉频率维(只剩振幅+瞬态τ)/ `ht 0` 关节律 /
   `pt 20` 固定 T(频率维强制消失)——可分离各通道对弁別率的贡献
