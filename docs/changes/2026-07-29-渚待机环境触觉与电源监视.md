## 1. 「渚(なぎさ)」— 待机环境触觉(兼保活)

不用生硬的"保活脉冲",而是设计成**环境触觉**:待机时竿像放在水边,
每 12–18 秒(随机)一次"浪拍岸"的轻柔涌动。

**波形设计**(`haptics.cpp` 的 `HAPTIC_WAVE` / `waveSample()`):

```
一次浪 ≈ 2.6s:
  主峰: sin² 包络的平滑隆起(1.6s)         ← 浪涌上来
  回浪: 0.4× 振幅的小峰(1.4s 起,1.2s 长) ← 浪退回去的"哗——沙"
载波: fc(60Hz 共振点),振幅默认 0.35,每次 ±20% 随机
间隔: 平均 45s ±20%(`wi` 可调 5–120s)
入场延迟: 进入待机后 1.5–4s 出现第一次浪
```

**底流(undercurrent)**:浪与浪之间由一条连续的低频保活音填充
(默认 28Hz / 振幅 0.35,`wf`/`wk` 可调)。原理:28Hz 远低于加振器共振点
(Fs≈50–60Hz),机械输出按约 -12dB/oct 急剧衰减 → **手感几乎为零**;
但音圈阻抗仍是直流阻值 ≈4Ω → **电流照常流动**(约 60mA 级)。
因此浪的间隔无论多长,充电宝都不会看到"无负载",判停窗口多短都不怕。
浪只负责氛围,底流只负责保活,二者解耦。

**设计依据**:电通大坂本真树研 × TOTO 的水触感研究(2025)——舒适的水触感
位于"ふわふわ/さらさら"方向:强度低、包络平滑无棱角;强度大/粗糙则不适。
故包络全部用 sin² 圆滑曲线、振幅偏低。低频感由 AM 载波承载(与本项目
アタリ改良同一方法)。

**出现状态**:仅 IDLE / CAUGHT / FAILED。WAITING→FIGHTING 全程无渚,
**实验刺激条件不受污染**。战斗间隙(3–8s)远短于充电宝判停窗口(30–60s),
且振动阶段电流大,不会触发判停。

**串口命令**:

| 命令 | 作用 | 默认 |
|------|------|------|
| `wa <0-1>` | 浪的振幅(0=关) | 0.35 |
| `wi <sec>` | 浪的平均间隔 | 45s |
| `wk <0-1>` | 底流振幅(0=关) | 0.35 |
| `wf <Hz>` | 底流频率(16–45Hz) | 28Hz |
| `wd <1-4>` | 底流软削顶系数:峰值(体感)不变,把正弦"削胖"提高 RMS 电流。1≈纯正弦,2≈电力 1.4 倍,4≈1.7 倍 | 2.0 |

**调参指引**:接上加振器后,若待机时仍能隐约感到持续微震,优先降 `wf`
(往 20Hz 方向,离共振点更远)再降 `wk`;若充电宝仍判停,先升 `wd`(不增
体感)再考虑 `wk`。注意 `wd` 大时高次谐波(3f≈84Hz)可能带来极轻微的
"嗡"感——察觉到就把 `wd` 降回 1.5–2;若同时想降 `wf`,避开 20Hz
(3×20=60Hz 恰好撞共振点)。浪的存在感用 `wa`/`wi` 独立调,与保活无关。

## 2. 电源监视器(屏幕左上角,2026-07-29 前一日实装)

由于 M5StickS3 有内置电池,"屏幕亮着"无法证明外部供电正常。
现左上角每秒刷新(BQ27220 电量计,M5.Power API):

| 显示 | 含义 |
|------|------|
| `EXT +xxmA xx%`(绿) | 外部供电中(内置电池充电中) |
| `PWR? +0mA 100%`(黄) | 电池满、电流≈0 — 通常也是外部供电(断电会立即变橙) |
| `BAT -xxmA xx%`(橙) | **外部电源已断**,靠内置电池运行(振动会失效!) |

**demo 前检查**:长按充电宝按键启动输出 → 确认左上角为绿/黄。
中场休息后同样先看一眼再开始。

## 3. 采购建议(留档)

后续补购充电宝时,选带「低電流モード」的型号(如 ELECOM DE-C33L 系列),
可从根源避免判停;或在 5V/GND 间并 47Ω/2W 假负载电阻(约 106mA 恒定,
无声无感,续航约 6h)作为硬件方案。
