## 1. 改动背景

方案书诊断了"振动真实感不强"的三个结构性短板:

1. アタリ的 10/23Hz 直接正弦低于 MAX98357A 的 ~14Hz 高通和激振器共振频率
   (Fs≈50–60Hz),**低频根本到不了手上**;
2. 真实アタリ是"敲击瞬态 + 竿体余振",不是稳态周期正弦;
3. 引き感的连续非对称振动自带"嗡嗡"副作用,破坏"被拉"的错觉。

本次按方案书建议的优先级,落地了方案一、二、三和方案四的两个事件,
方案五(音触同步 + IMU 实录校准)属线下实验任务,未含在本次代码改动内。

## 2. 各方案的具体改动

### 方案一:AM 载波绕过硬件高通(haptics.cpp)

- 10+23Hz 不再直接输出,改为作**包络**调幅一个共振点附近的载波:
  `[0.5 + 0.5·(0.58·sin2π10t + 0.42·sin2π23t)] × sin(2π·fc·t)`
- 载波 fc 默认 60Hz(EX25FHE2-4 装竿后的预计共振区 50–80Hz),
  新增串口命令 **`fc <Hz>`**(30–150Hz)供实机扫频。
- 扫频确定后应把 `haptics.cpp` 的 `CARRIER_HZ_DEF` 固化为实测值。

### 方案二:アタリ瞬态化——敲击事件模型(haptics.cpp)

NIBBLE/BITE 从"稳态正弦 burst"改为**敲击事件序列**,每个事件:

| 阶段 | 波形 | 含义 |
|------|------|------|
| click | 3ms 半正弦冲击(宽带) | "竿尖被点了一下"的物理瞬态 |
| ringdown | `e^(−t/τ) ×` 10+23Hz 包络 `× sin(2π·fc·t)` | 竿体余振(AM 表达) |

- **NIBBLE**:稀疏单敲"コツッ",间隔 350–900ms 随机,30% 概率二连敲,
  τ ∈ [0.75, 1.25]×tt;
- **BITE**:密集连敲"ココココッ",间隔 70–140ms,τ ∈ [0.5, 0.75]×tt
  (更短促干脆),振幅 60%→100% 渐强;
- 余振时定数默认 120ms,新增串口命令 **`tt <ms>`**(30–400ms)可调。

### 方案三:运动耦合引き感(main.cpp)

- FIGHTING 的引き振幅增加**陀螺仪门控层**(CHI 2025 motion-coupled
  pseudo force):竿动(角速度→220°/s 门控全开)时全振幅,静止时衰减到
  **35% 张力底噪**;立ち上がり即时(系数 0.5)、回落约 300ms(系数 0.06)。
  利用感觉衰减机制,在保留牵引力错觉的同时抑制"嗡嗡感"。
- 新增串口命令 **`mc 0|1`** 单独开关此层(A/B 对比用),默认开。
- 脉冲间隔 T 的联动范围从 12–22ms 改为 **16–26ms**,即周期 21–31ms,
  以牵引错觉最优的 40Hz(周期 25ms,T=20ms)为中心(Tanaka ら 2020);
  `haptics.cpp` 的 `PULL_INTERVAL_DEF` 同步 17→20ms。

### 方案四(部分):FIGHTING 事件层(main.cpp + haptics.cpp)

鱼行为重抽(每 0.55–1.1s)发生**状态切换**时叠加触觉事件:

- **突进 onset**:叠加一次大幅瞬态敲击(`hapticTriggerTap(1.0)`)——
  "猛地一拽"的开始感;
- **休息 onset**:振动**骤停 120–300ms 再恢复**(`hapticTriggerSlack`)——
  "糸がふっと緩む"的 line-slack 线索(SIGGRAPH Asia 2024 证明极有效)。

方案四的其余事件词汇(甩头 2–4Hz 脉冲组、出线棘轮 click、1/f 张力纹理)
留作后续增量添加。

## 3. 实验对照条件的保留

- **`ir 0`** 现在整体回退到**文献准拠基线**:
  - アタリ = 10+23Hz 直接正弦 burst(才木ら 2016 原样);
  - 引き = 恒定振幅 0.7、严格周期(高椋ら 2016 原样),
    无抖动/摆动/运动耦合/事件层。
- **`ir 1`**(默认)= 本次的全部改良设计。
- `mc 0|1` 可在改良模式内再单独切分运动耦合这一个变量。

即主观评价实验可做:基线(ir 0) vs 改良(ir 1),以及改良内部的
运动耦合有无(mc 0 vs mc 1)两组对照。

## 4. 新增/变更的 API 与命令一览

**haptics.h 新增接口**

| 接口 | 作用 |
|------|------|
| `hapticSetCarrier(float hz)` / `hapticCarrier()` | AM 载波频率(30–150Hz) |
| `hapticSetTapTau(int ms)` / `hapticTapTau()` | 敲击余振 τ(30–400ms) |
| `hapticTriggerSlack(int ms)` | PULL 中骤停 50–500ms(非 PULL 模式忽略) |
| `hapticTriggerTap(float amp)` | PULL 中叠加一次瞬态敲击(非 PULL 模式忽略) |

**串口命令(115200bps)**

| 命令 | 新/旧 | 作用 |
|------|------|------|
| `fc <Hz>` | 新 | AM 载波频率,共振点扫频用 |
| `tt <ms>` | 新 | 敲击余振时定数 τ |
| `mc 0\|1` | 新 | 运动耦合开关 |
| `ir 0\|1` | 语义变更 | 0=文献准拠基线(现在也切换アタリ波形),1=改良(默认) |
| `t / pa / pt / na` | 不变 | 强制模式 / 引き振幅 / T 固定 / アタリ振幅 |

## 5. 烧录后的验收与调参步骤

1. `pio device monitor -p COM3 -b 115200` 打开监视器;
2. **定载波**:`t n` 强制アタリ → `fc 40` 起每 10Hz 扫到 `fc 120`,
   记录体感最强的频率(= 实际共振点),回改 `CARRIER_HZ_DEF`;
3. **验敲击感**:确认 NIBBLE 是"被点了一下"而非"手机嗡嗡";
   太绵长 → `tt 80`,太干瘪 → `tt 180`;
4. **验引き**:`t p` 确认牵引方向朝手前(反了改 `PULL_POLARITY` 或对调
   OUT+/OUT−);
5. **验运动耦合**:`t g` 回游戏,FIGHTING 中静止 vs 泵竿对比振幅变化;
   `mc 0` 关掉再对比"嗡嗡感"差异;
6. 可选:`ir 0` 体验文献基线,确认对照条件工作正常。
