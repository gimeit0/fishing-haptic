## 1. 泄力打滑 drag slip(改进 4,对应短板 W5)

真实钓鱼中泄力器"嗒嗒嗒"出线是最标志性的反馈,同时把断线从"突然惩罚"
变成"有触觉前兆的可挽回状态"。

**规则**(`tensionFightUpdate`):

| 倾角区间 | 行为 |
|----------|------|
| 18–48° | 正常负荷:进度充填,振动=鱼的抵抗(不变) |
| **48–55°(新)** | **打滑**:进度不充填反而以 0.6× 倒退,1250Hz 嗒嗒声(110ms 间隔),画面 DRAG SLIPS(黄) |
| >55° | 打滑继续 + 原有 2800Hz 警告,连续 1.2s 断线(规则不变) |

**触觉**(`haptics.cpp` 新增,波形级,不依赖 16ms 游戏循环):

- `hapticSetSlip(bool)`:on 期间在 PULL 上重叠 click train——3ms 半正弦
  + 18ms 短余韵(载波),间隔 55–90ms 随机;同时基础张力 duck 到 55%
  (糸が出て張力が抜ける)。已开始的 click 在 off 后播完,无切断爆音。
- 打滑状态与 tap(突进/段完成瞬态)状态分离,互不干扰。

**调参**:`hd <deg>` 改打滑开始角(默认 48,钳位 30–55)。

## 2. 抗适应:引き込み节律 + 段内渐增(改进 1,对应短板 W1)

持续同频振动数秒内触发振动触觉适应(频率特异的感受器疲劳),
主观强度下降——HOLD 的 2.5–4s 连续负荷正好踩中。两层对策:

- **引き込み节律**(`hapticSetTug`,haptics 波形级):负荷中 PULL 分节为
  「拉入 250–400ms(全幅)→ 微歇 90–140ms(降至 42%)」随机循环,
  包络 ~16ms 时定数平滑。微歇不降到 0,与 slack 事件(骤停=糸が緩む
  合図)保持可区分。`ir 0`(文献基线)时自动关闭。
- **段内渐增**(main.cpp):振幅乘 `1 + 0.18 × (tenSegMs/tenSegHold)`,
  充填越满越强,补偿适应造成的主观衰减,顺带奖励"快满了"。

**调参**:`ht 0|1`(默认 on)。调研中的第三层对策(低/高频通道交替)
刻意未实装——载波跳到 200Hz 会脱离牵引错觉的有效域(40Hz±),
留给腱振动(P1.5,第二执行器)方案。

## 3. 鱼尺寸→频率+振幅双映射(改进 3,对应短板 W3)

30Hz 低频振动使手持物体被感知得更重(重量错觉文献,效应量大;
高椋ら 2016 也指出振幅・周波数可变调鱼大小印象)。原来尺寸只映射
振幅(0.55–1.0),现补上频率维:

- **脉冲间隔 T 偏置**(HOLD 限定):`T += lerp(-3ms, +5ms, fishSize01)`。
  大鱼周期 5+T 最长约 34ms(~29Hz,重・粗),小鱼最短约 18ms(~55Hz,
  轻快)。刻意收在牵引错觉有效域(40Hz±)附近,不牺牲拉拽感。
  `pt` 固定 T 时不叠加(单变量实验优先)。
- **段完成瞬态的"分量"**:`hapticTriggerTap(amp, tauMs)` 新增可选 τ 参数,
  段完成敲击的余振 τ = 60 + 80×size(小鱼 60ms 脆,大鱼 140ms 沉)。

**调参**:`hf 0|1`(默认 on)。

## 4. 接口与命令变更一览

| 项 | 变更 |
|----|------|
| `haptics.h` | 新增 `hapticSetTug(bool)` / `hapticTug()` / `hapticSetSlip(bool)`;`hapticTriggerTap(float amp, int tauMs = 0)`(旧调用不受影响) |
| 串口命令 | `ht 0\|1` 节律开关 / `hf 0\|1` 尺寸频率开关 / `hd <deg>` 打滑角 |
| HOLD 画面 | 新增 DRAG SLIPS! ease off(黄色)提示层级:RAISE(橙)→ HOLD(绿)→ DRAG SLIPS(黄)→ TOO HIGH(红) |

三项改进 + 既有 `ir`/`mc` 全部可独立开关 → 预备评价可做干净的
单变量 A/B(如 `ht 0` vs `ht 1` 的 5 分钟适应对比)。

## 5. 待实机确认的点

- 打滑 click train 的间隔(55–90ms)和 duck 比例(55%)是拍脑袋初值,
  上竿后感受"像不像泄力器出线"再调。
- 大鱼 T=+5ms 后牵引感是否仍明确(周期 34ms ≈ 29Hz,已在文献推荐的
  T≥12ms 内,但离 40Hz 最优点有距离)——不行就把 BIG 偏置缩到 +3。
- 段内 +18% 渐增与倾角张力系数(0.85–1.15)叠加后,满充填+高倾角时
  总增益 ≈ 1.36×sizeFac,注意是否触顶(hapticSetPull 内部钳到 1.0)。
