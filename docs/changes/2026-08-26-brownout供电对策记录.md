# 记录:BIG 条件 brownout 供电问题 — 诊断结论与对策清单

> 日期:2026-08-26,分支 `hold-mode-v3`
> 状态:**软件对策已实装并烧录**(2号机;1/3号机同步中);
> **硬件对策为待实施方案**,记录于此备后续实施——发表时可如实表述为
> "固件侧限幅已稳定运行,去耦电容与独立供电为已设计待实施的硬件对策"。

## 1. 现象与诊断结论

**现象**:BIG 条件战斗中黑屏重启,SML 不发生。

**诊断**(证据链):

1. IDLE 画面新增的复位原因显示确认为 **`rst:BROWNOUT`**(红)——供电垂下,
   非程序崩溃(崩溃前串口无 panic 堆栈,USB 直接掉线,亦佐证);
2. 串口日志显示板子**撑过 3.2s 的持续振动段**、死于段完成瞬态的一刻
   ——瞬态电流尖峰是压垮点;
3. 充电宝 ELECOM DE-M04L-3200(3200mAh / 5V·2.1A / 单口):额定电流足够
   **平均值**(~0.3A),垮在**瞬态**——5ms 类方波脉冲的电流阶跃(满幅时
   峰值 ≈1A)快于"充电宝稳压环路 + USB 线阻 + M5 内部供电路(M5PM1)"
   的响应,瞬间把 3.3V 轨拖过 ESP32-S3 的 brownout 阈值;
4. M5 官方文档佐证:StickS3 电池供电时内置扬声器音量 >75% 即可能重启
   ——瓶颈大头在 M5 自身的 5V 通路,换更强充电宝无法根治;
5. BIG 特有的三重叠加:振幅顶格 × 基频 29Hz(共振点 50–60Hz 以下,
   音圈阻抗跌至直流电阻最小值,同电压电流最大)× 每段 3.2s 连续输出。

## 2. 已实装的软件对策(当前烧录版本)

| 对策 | 内容 | 位置 |
|------|------|------|
| 峰值限幅器 `pl` | PULL **混音后**(基线+瞬态敲击+泄力click 合算)最终钳制,默认 0.60。教训:只钳基线会被满幅瞬态漏掉,实机曾死于段完成敲击 | `haptics.cpp` 最终钳制 / `PULL_PEAK_LIMIT_DEF` |
| 战斗中降背光 | FIGHTING 中 255→170(两条件共通),给功放让几十 mA | `BRIGHT_FIGHT` |
| 对比度下移 | 尺寸弁別靠相对差:SML 振幅下限 0.55→0.40、SML 频率上探(T−5ms,贴共振点),BIG 不再顶供电天花板,且两条件突进不再被钳位削平成同感 | `TEN_AMP_MIN` / `TEN_T_BIAS_SML` |
| 复位原因显示 | IDLE 画面 `rst:` 行,BROWNOUT 红字——脱离串口即可诊断 | `esp_reset_reason()` |

副作用:满幅动态范围让出 40%。**硬件对策落地后串口 `pl 1` 即可恢复满幅**
(长期稳定后可把 `PULL_PEAK_LIMIT_DEF` 改回 1.0 并重烧)。

## 3. 待实施的硬件对策(按推荐顺序)

### 3.1 VIN–GND 并联去耦电容(首选,预计单独即可解决)

**元件**:铝电解电容 **1000µF**(470–2200µF 皆可,两颗 470 并联亦可)/
耐压 **16V**(至少 10V)/ 低 ESR 优先 / 有极性 / 三台+备用共购 4–5 颗。

**接法**:电容**并联**横跨在 MAX98357A 的 VIN 与 GND 引脚之间:

```
M5 5V  ──长导线──────┬───▶ VIN   (MAX98357A)
                     │+
                 [1000µF]  ← 必须贴着功放模块 (≤2-3cm)
                     │−
M5 GND ──长导线──────┴───▶ GND
```

三条铁则:①**长脚(+)接 VIN、壳上色带侧(−)接 GND**,反接会鼓包喷液;
②贴功放装,装在 M5 端无效(原理是就地供出 5ms 脉冲电流,长导线上只流平均);
③是并联不是串联,串进电源线功放直接断电。
(图解参考:接线卡 artifact「功放电容接线卡」,含全图/极性/错误示例)

**验收**:BIG 连打 → `pl 0.75` → `pl 1` 逐级放开,`rst:` 全程保持灰色即过关。

### 3.2 功放独立 5V 供电(根治)

第二个充电宝(或一分二 USB 线)直接给功放供电,绕开 M5 内部窄路:

```
充电宝A ──USB-C──▶ M5(GPIO4/5/6 + GND 共 4 根连功放,5V 线拆除!)
充电宝B ──剪线──── 红=+5V → 功放 VIN / 黑=GND → 功放 GND(与 M5 共地)
```

铁则:**GND 必须共通,两个 5V 绝对不能相连**(M5 官方警告向输出口灌电有
短路损坏风险)。注意充电宝 B 只带功放(静态 2.4mA)会低负载判停——
实验前按键激活,或串口 `wk 0.35` 启用底流保活(该电流只走 B 路)。

### 3.3 GAIN 引脚降增益(零成本)

GAIN 引脚**直接接 VIN = 6dB**(默认悬空 9dB,电流约减半);
经 100kΩ 接 VIN = 3dB。⚠ 方向勿反:接 GND 是**升**到 12dB。

三项对策**叠加有效**,互不冲突。最小可行组合:仅 3.1(电容)。
