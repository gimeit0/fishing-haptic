# 疑似釣り体験プロトタイプ (Fishing Haptic Prototype)

> **第2版 (v2)** — 2026-07-27 更新
> 触覚波形の全面改良(AM キャリア / 敲撃イベント / 運動結合 / slack イベント)と、
> やり取りの新モード「張力保持 (HOLD)」を実装した版。
> 変更の詳細は [docs/changes/](docs/changes/) の説明文書、
> 改良の設計根拠は [docs/IMPROVEMENT_PROPOSAL.md](docs/IMPROVEMENT_PROPOSAL.md) を参照。

## プロジェクト概要

のべ竿型・非接地・小型振動装置で「アタリ」と「引き」の触覚を切替提示する VR 釣り具プロトタイプ。
M5StickS3 単体でも 8 状態の釣り体験シミュレータとして動作し、外付けアンプ+加振器を
接続すると触覚提示が有効になる。

## ハードウェア構成

| 部品 | 型番 | 役割 |
|------|------|------|
| メインコントローラ | M5StickS3 (ESP32-S3) | 波形生成・I2S 出力・IMU・LCD |
| デジタルアンプ | MAX98357A | I2S → アナログ + Class-D 増幅 |
| 振動子 | Dayton EX25FHE2-4 (4Ω/24W) | ボイスコイル型エキサイター |
| 電源 | Anker PowerCore 5000 | 5V 供給 |

## 配線(M5StickS3 → MAX98357A)

| M5StickS3 | MAX98357A | 信号 |
|-----------|-----------|------|
| 5V | VIN | 電源 |
| GND | GND | グランド |
| GPIO4 | BCLK | ビットクロック |
| GPIO5 | LRC | LR チャンネル選択 |
| GPIO6 | DIN | デジタル音声データ |

MAX98357A の OUT+/OUT- は EX25FHE2-4 に接続。

## ゲームフロー(8 状態)

```
IDLE → CASTING → WAITING → NIBBLE → BITE → FIGHTING → CAUGHT / FAILED
(BtnA)  (自動)    (3-8s)   (アタリ弱) (合わせ!) (やり取り)   (結果表示)
```

- **NIBBLE**: 前アタリ。まばらな敲撃振動「コツッ」
- **BITE**: 本アタリ。密な連打振動+画面警告。1 秒以内に竿を煽る(IMU |a|>1.5g)と成立
- **FIGHTING**: やり取り。2 モードあり(IDLE 画面の BtnB / シリアル `fm` で切替):
  - **PUMP(既定)**: 陀螺儀で上提を検出し、マーカーをスイートゾーンに維持して充填
  - **HOLD(第2版で追加)**: 竿を高く傾けて保持している間だけ魚の抵抗=振動を提示、
    竿を戻すと無振動。保持で分段バーを充填しきると捕獲。魚サイズ(毎回抽選)が
    振動の強弱・段数・保持時間・釣果表示に反映される

## 触覚刺激デザイン(第2版)

| 刺激 | 波形 | 根拠 |
|------|------|------|
| アタリ | 敲撃イベント = 3ms 衝撃 + e^(−t/τ)·[10+23Hz 包絡]·sin(2π·fc·t) の AM 余振 | 才木ら 2016 + 瞬態化/AM 改良 |
| 引き | 5ms 高 + T ms 低の非対称矩形波(T=16–26ms、40Hz 中心)+ 運動結合/傾き門控 | 高椋ら 2016 + Tanaka ら 2020 |
| イベント | 突進 onset=瞬態敲撃、休息 onset=振動骤停(line slack) | SIGGRAPH Asia 2024 ほか |

第1版からの主な変更(詳細: [docs/changes/](docs/changes/)):

1. **AM キャリア方式**: 10/23Hz を直接出さず包絡としてキャリア(既定 60Hz、`fc` で
   スイープ可)に載せ、アンプの ~14Hz HPF と加振器共振の減衰を回避
2. **アタリの瞬態化**: 連続正弦バースト → 敲撃イベント列(NIBBLE=単発、BITE=連打漸強)
3. **運動結合引き感**: 竿が動いている間だけフル振幅(CHI 2025 motion-coupled 方式)
4. **FIGHTING イベント層**: 突進瞬態 / 休息 slack(骤停)
5. **張力保持モード**: 上記 HOLD モード(研究室メンバーの提案に基づく)
6. **対照条件**: `ir 0` で第1版相当の文献準拠波形(才木ら/高椋ら)に全体復帰可能
   → 評価実験の「基線 vs 改良」組内比較用

## シリアルコマンド(115200bps、予備評価用)

| コマンド | 機能 |
|----------|------|
| `t 0\|n\|b\|p` / `t g` | 触覚モード強制 / ゲーム連動に戻す |
| `pa <0-1>` | 引き振幅スケール |
| `pt <ms>` | パルス間隔 T 固定(`pt 0` で自動 16–26ms) |
| `na <0-1>` | アタリ振幅 |
| `ir 0\|1` | 0=文献準拠基線(対照条件) / 1=改良版(既定) |
| `fc <Hz>` | AM キャリア周波数(共振点スイープ用、30–150Hz) |
| `tt <ms>` | 敲撃余振の時定数 τ(30–400ms) |
| `mc 0\|1` | 運動結合 on/off(PUMP モードのみ) |
| `fm 0\|1` | 戦闘モード 0=PUMP / 1=HOLD |

詳しい操作説明は [docs/HAPTICS_GUIDE.md](docs/HAPTICS_GUIDE.md)。
